Set up your EmberStorm

Three steps, about ten minutes. You'll need the setup code on the label on the bottom of the box.

  1. Plug it in

    Connect the power, and a network cable from the box to your router. The first start takes a few minutes.

  2. Open EmberStorm

    On a phone, get the EmberStorm app - it finds your new box on its own:
    • Android: from the releases page (the android ones).
    • iPhone: coming soon to the App Store. Until then, use a computer, or Safari on the phone (below).
    Or on any computer or tablet at home, open soundstorm.local in the web browser.

  3. Enter your setup code

    Turn the box over: the label on the bottom has your setup code and a QR code. Scan it with the app or your phone's camera, or type the code. Then choose your name and password - the box is yours.

If it doesn't find the box

  • Make sure your phone or computer is on your home Wi-Fi, not a guest network or mobile data.
  • Give it a few more minutes the first time: the box is getting everything ready.
  • If soundstorm.local doesn't open, plug a monitor into the box: its screen shows the address to type and the setup code.
  • Lost the label? The setup code is also shown on that screen. Or write to hello@emberstorm.app with the serial number from the box.
